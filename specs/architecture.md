# Multi-Agent Brain Orchestrator — 系统架构规格

## 架构概览

```
┌─────────────────────────────────────────────────────────────────────┐
│                     Harness 协作管控底座                              │
│  ┌───────────┐  ┌───────────┐  ┌───────────┐  ┌────────────────┐   │
│  │ Scheduler │  │ MetaRules │  │ Validator │  │ SnapshotManager│   │
│  │ (调度引擎) │  │(元协作规则)│  │(安全校验) │  │  (快照归档)    │   │
│  └───────────┘  └───────────┘  └───────────┘  └────────────────┘   │
│                                                                      │
│  生物启发抽象映射（全部在 Harness 层实现）:                             │
│  PV 中间神经元 → 快速抑制/去抑制 → 冲突仲裁 + 死锁解除                  │
│  胶质稳态理论   → 离子缓冲/突触修剪 → 背压控制 + 冗余回收              │
└─────────────────────────────────────────────────────────────────────┘
                                    │
        ┌───────────────────────────┼───────────────────────────┐
        ▼                           ▼                           ▼
┌───────────────┐         ┌───────────────┐         ┌───────────────┐
│ LeadResearcher│         │ BrainSubsystem│         │   Workers     │

│               │         │               │         │               │
│ - 任务分解     │         │ - 常量池      │         │ - Researcher  │
│ - 任务分配     │         │ - 推理内核    │         │ - Coder       │
│ - 结果聚合     │         │ - 外部接口    │         │ - Reviewer    │

```

## 核心约束

1. **Orchestrator-Worker 主架构**：LeadResearcher 是唯一编排者，所有 Worker 仅执行分配的子任务
2. **Harness 外层管控**：所有调度、规则、校验、归档由 Harness 统一管理
3. **生物启发仅抽象**：PV 中间神经元和胶质稳态理论仅作为设计灵感，抽象为元机制后全部实现在 harness 模块
4. **B1-Final 永久冻结**：brain_subsystem 模块禁止修改任何常量和内核逻辑
